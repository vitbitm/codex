# Nebula QA Studio

Премиальный одностраничный сайт портфолио для студии тестирования ПО и веб-сайтов. Проект работает на чистом Node.js без внешних зависимостей и включает защищённую админ-панель для редактирования текста, списков услуг, процесса и контактных данных.

## Возможности

- 🎨 Стильный неон-глассморфизм дизайн с плавными анимациями появления блоков.
- 🧩 Гибкая структура контента: услуги, процесс, метрики, отзывы и контакты редактируются через панель.
- 🔐 Простая авторизация в админке по паролю (по умолчанию `qa-premium`, можно переопределить через переменную `ADMIN_PASSWORD`).
- 💾 Контент хранится в `data/content.json` и сохраняется после перезапуска сервера.

## Запуск

```bash
npm start
```

Сервер поднимется на `http://localhost:3000`.

## Работа с админ-панелью

1. Откройте `http://localhost:3000/admin/login`.
2. Введите пароль (`qa-premium` или значение из `ADMIN_PASSWORD`).
3. Отредактируйте тексты, добавьте услуги, этапы, метрики и отзывы.
4. Нажмите «Сохранить изменения» — данные обновятся на сайте моментально.

Контент хранится в JSON, поэтому изменения можно в любой момент откатить или внести вручную через `data/content.json`.

## Структура

- `app.js` — HTTP-сервер, отрисовка публичной страницы и админ-панели.
- `data/content.json` — источник контента.
- `public/css` и `public/js` — стили и скрипты для сайта и админки.

## Переменные окружения

- `PORT` — порт сервера (по умолчанию `3000`).
- `ADMIN_PASSWORD` — пароль входа в админ-панель.

## Лицензия

Проект распространяется под лицензией ISC (по умолчанию npm). Вы можете адаптировать дизайн и функциональность под нужды своей студии.

## Как скачать файлы на компьютер

Есть два основных способа получить исходники локально:

### 1. Через Git

1. Установите Git, если он ещё не установлен.
2. Выполните в терминале команду:
   ```bash
   git clone <URL_репозитория>
   ```
3. Перейдите в созданную папку `cd <название_папки>` и запустите проект как описано выше.

### 2. Скачивание ZIP-архива

1. Откройте страницу репозитория в браузере.
2. Нажмите кнопку **Code** (или «<> Code») и выберите **Download ZIP**.
3. Распакуйте архив у себя на компьютере и запустите проект из полученной папки.

После загрузки любым способом можно редактировать файлы и обновлять контент через админ-панель или напрямую в редакторе.
