# Tinery QA Studio

Небольшое веб‑приложение для студии тестирования Tinery: авторизация, админ‑панель для управления пользователями и доска задач, доступная после входа.

## Запуск
1. Установите зависимости:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   ```bash
   python app.py
   ```
   Приложение поднимется на `http://localhost:8000`.

## Учётные данные по умолчанию
- Логин: `admin`
- Пароль: `admin123`

Можно переопределить переменными окружения `ADMIN_USER` и `ADMIN_PASSWORD`, а секретный ключ — переменной `SECRET_KEY`.

## Функции
- Вход и выход из аккаунта.
- Панель задач с фильтрацией по назначению/автору и обновлением статусов.
- Создание задач с описанием, статусом и назначением коллегам.
- Админ‑панель для создания новых пользователей и выбора роли (admin/member).

## О бренде
Дизайн использует палитру из брендбука Tinery: акцентный бирюзовый, светлый фон и тёмный текст, шрифт Inter.
