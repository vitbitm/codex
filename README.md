# Automated Web Testing Suite

Веб-приложение, которое моделирует запуск комплексного тестирования сайтов без участия человека. Пользователь вводит домен, выбирает виды тестирования и получает результаты после автоматического выполнения.

## Возможности
- Поддержка нескольких направлений тестирования (performance, security, SEO, accessibility, content, functional)
- Асинхронный запуск прогонов с отображением статуса и прогресса
- REST API на FastAPI и современный интерфейс без перезагрузки страницы

## Запуск локально
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите backend:
   ```bash
   uvicorn app.main:app --reload
   ```
3. Откройте `frontend/index.html` в браузере (можно через простой HTTP-сервер, например `python -m http.server` из папки `frontend`).
4. В интерфейсе укажите адрес backend (если он доступен по другому домену/порту) либо откройте HTML из того же происхождения.

## API
- `GET /api/tests/available` — список доступных тестов
- `POST /api/tests` — запуск тестов `{ "domain": "example.com", "test_types": ["performance"] }`
- `GET /api/tests/{run_id}` — статус и результаты прогона
- `GET /api/tests` — список всех прогонов текущего экземпляра сервиса

## Архитектура
- `app/` — backend на FastAPI, управляющий очередью тестов и выдающий результаты
- `frontend/` — статический интерфейс для запуска и мониторинга прогонов

> **Примечание:** текущая реализация использует детерминированную симуляцию результатов. Для интеграции с реальными инструментами тестирования необходимо заменить обработчики в `app/testing.py` на конкретные проверки и подключить внешние сервисы.
