# QA Spark Website

Легковесный сайт для компании по тестированию ПО с встроенной мини-CMS.

## Запуск

```bash
npm install
npm start
```

> Пароль администратора по умолчанию: `qualityfirst`. Его можно изменить через переменную окружения `ADMIN_PASSWORD`.

- Главная страница: http://localhost:3000/
- Панель управления: http://localhost:3000/admin.html

Контент хранится в файле `content.json` и обновляется сразу после сохранения в панели.
